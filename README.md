# ai-sandbox

AI 学习沙盒：借助 AI 快速学习任意领域的知识与技术，刻意训练对 AI 产出的判断力。

定位：这是一个**学习状态管理系统**，不是笔记仓库。每个学习主题走完整生命周期：学习 → 考验 → 归档 → 按记忆模型抽检 → 复习 → 再归档。AI 通过仓库记录持续掌握学习者的状态（会了什么、什么该复习、下一步学什么）。

## 使用方式

新会话开场，对 AI 说：

- `继续学习` — AI 读 `learning/INDEX.md` 恢复学习画像，汇报进行中主题与到期复习，然后继续。
- `今天该复习什么，考我吧` — AI 按记忆模型现算各知识点可提取性，先考最危险的。
- `我想学 <主题>` — AI 开新主题目录，进入讲解 → 复述 → 纠正的学习循环。
