# AGENTS.md

本仓库是 AI 学习沙盒。规则分 `[Required]`（必须遵守）与 `[Default]`（默认遵守，偏离需记录原因）两级。

## 新会话开场 `[Required]`

1. 读 `learning/INDEX.md` 恢复学习画像。
2. 汇报：进行中的主题、需要复习的内容（现算知识点可提取性，列出最危险的几个）。
3. 等用户选择方向后再行动。

## 考官纪律 `[Required]`

本仓库中 AI 同时是老师与考官，必须主动对抗迎合倾向：

- 判定用户"学会了/判断正确"时，必须同时给出**反方证据**：换措辞重问、边界反例、要求指出 AI 方案的缺陷等，证明用户不是复述措辞、礼貌附和或蒙对。没有反方证据的"通过"无效。
- AI 自己的讲解只是一审查见。考验的标准答案必须挂外部参照：官方文档、真实运行结果、公认事实。
- 用户不理解时直说，禁止为了流畅而降低判定标准。

## 记忆模型 `[Required]`

复习调度按**知识点**级进行，用 FSRS 风格的记忆三量建模：

- 每个知识点在 `challenges.md` 中逐条记录：最近考核日期、结果（忘了/模糊/记得）、稳定性 S（天）、难度 D。
- 可提取性 R = (1 + t/(9·S))^(-1)，t 为距上次考核的天数，考核时现算。
- 用户问"该复习什么"时：算出所有知识点的 R，R < 0.9 的按最危排序出考卷。快忘的必然先出现，不依赖固定日历，无定时任务。
- 结果更新：记得 → S 递增（大致按 1/3/7/14/30/60 天节奏倍增）；模糊 → S 小幅递增；忘了 → S 回退至接近 1、D 上升。D 高的知识点即使通过，S 增长也放缓。

## 主题生命周期 `[Required]`

- 开新主题：在 `learning/` 下建 `YYYYMMDD-主题名/` 目录（开题日期 + 可读主题名，平铺不分类），内含四个文件：
  - `README.md` — 主题状态卡：状态、知识点汇总表（各点最新 S/D/R）、薄弱点、参考资料链接。
  - `notes.md` — 学习笔记：讲解 → 用户复述 → AI 纠正的沉淀，是消化后的产物，禁止整段粘贴 AI 原话。
  - `challenges.md` — 考验记录：追加式，每次考验一段（日期、考了哪些知识点、用户答案要点、判定与反方证据、S/D 更新）。
  - `reviews.md` — 复习记录：追加式，抽检未通过后的复习过程与结果。
- 状态流转：`learning` → 考验通过 → `mastered`（进入记忆维护期）→ 任意时刻可 `paused`。考验未通过不改变状态，只更新记忆数据。
- 同一主题的迭代都在原目录进行，不为"再学一遍"开新目录。

## Demo 代码 `[Required]`

- 涉及可运行 demo 的主题，在主题目录下建 `demos/` 子目录；每个 demo 一个子文件夹，**必须**附极简 `README.md`：运行命令、预期观察点、对应知识点。复习时依据它独立重跑，"真实运行结果"是标准答案的外部参照。
- 运行环境按**每主题一个**管理：`demos/` 根下放一份依赖清单（requirements.txt / package.json 等），同主题 demo 共用一个环境；个别 demo 依赖冲突时才允许单独开环境并在该 demo README 中说明。
- 依赖清单落盘提交；安装产物与运行垃圾（node_modules、__pycache__、.venv、dist 等）已入 .gitignore，永不入库。

## 同步义务 `[Required]`

- 任何主题操作（开题、考验、复习、状态变更）必须在同一提交内同步 `learning/INDEX.md` 与该主题 `README.md` 状态卡。
- 任何治理规则改动（本文件、README.md、INDEX 结构），必须在同一提交内同步 `skeleton/` 下的对应模板，保持骨架始终是最新状态。
- `skeleton/` 是干净骨架的分发副本：AGENTS.md、README.md、learning/INDEX.md、.gitignore。分发时整体复制即可。

## 提交纪律 `[Required]`

- 小步提交：每完成一个独立小块（开题、一次考验、一次复习、一篇笔记）即提交。
- 格式：`<type>(<标签>): <内容>`，type 取 `learn`（学习内容）、`govern`（规则/骨架）、`fix`（修正记录错误）。标签用主题短名或 `meta`。
- 示例：`learn(k8s): 完成 Service 网络模型初考`、`govern: 考官纪律增加反方证据要求`。

## 范围与安全 `[Default]`

- 本仓库只承载学习活动。临时交接状态放 `.ai-work/`（已 ignore），不散落在源文件中。
- 笔记与记录不写入密钥、令牌等敏感信息。
