## 已固化验收规则

1. **归属权一问**（KP2）：含归属数据的按 ID 查询/操作接口，验收必问"查询条件里除了 ID 还有什么？"答不出归属限定，打回。公开数据不适用。
2. **自曝对撞**（KP1/KP2）：AI 自曝"什么输入会出错"的回答，逐句与需求对撞；"完美自信/全无故障模式"本身是红旗。
3. **注入二选一**（KP2b）：问"输入是拼进 SQL/模板/命令文本，还是作为独立参数？"拼进文本打回；结构成分（排序列、表名、路径）必须后端白名单。注意"异常"措辞 ≠ 承认"泄露"。
4. **客户端信任**（KP2b）：问"这个校验发生在哪一层？"——安全边界只承认后端；前端校验是体验优化。"双保险很安全"是红旗。
