## 薄弱点

- "前提全假 → 推理无效"的绑死误解刚纠正，2026-09-09 抽检确认修复。
- 结构直觉不稳、语义直觉强：C 题先造出同款错误结构又自我识破——判结构题时需刻意放慢。

## 已固化验收规则

1. **两轴分查**（KP1）：看 AI 的论证分两步——先查结构有效性，再逐个查前提真实性（尤其最像常识的那个）。结构完美 ≠ 结论可信。
2. **归因排除问**（KP1）：AI 给唯一归因时必问"排除了其他可能吗？列出其他原因、说明排除了谁凭什么"——列不全只能当假设。
