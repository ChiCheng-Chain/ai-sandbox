## 已固化验收规则

1. **两轴分查**（KP1）：看 AI 的论证分两步——先查结构有效性，再逐个查前提真实性（尤其最像常识的那个）。结构完美 ≠ 结论可信。
2. **归因排除问**（KP1）：AI 给唯一归因时必问"排除了其他可能吗？列出其他原因、说明排除了谁凭什么"——列不全只能当假设。注意"典型原因"≠"全部原因"，是局部推全局。
3. **排除检验**（KP2）：AI 缩小排查范围时，检查每步排除是否符合"若X则必有Y；无Y；故排除X"——不符合的排除是拍脑袋。
4. **范围滑动警戒**（KP2）：见"我们的X都→所有X都"句式，查结论主语范围是否比前提大一圈（范围+断言双重滑动）。
5. **候选池两问**（KP3）：AI 给诊断/归因时问"候选池里有谁？"（单成员=没诊断只有断言）+"用什么区分性证据切开的？"（无证据=拍脑袋选中）。
6. **伪概率审问**（KP3）：AI 说"通常/大概率/八成"时问"这个比例的样本是什么？跟眼前这个 case 匹配吗？"——未声明的归纳前提伪装成概率。
7. **处方来源问**（KP3）：AI 给具体数字的处方（扩容三台/重试三次）时问"这个数字怎么得出的？压测数据还是拍的？"
8. **反例搜索**（KP4/确认偏差）：对已形成的判断，强制执行"专门去找证明我错了的信息"——违反直觉，靠清单强制。
9. **独立估价**（KP4/锚定）：谈判/评估前先独立得出自己的数字，再听对方的。
10. **全样本校正**（KP4/幸存者偏差）：听到"某人/某案例"先问"没成/没活/没出声的在哪？"——把缺席者放回样本。"我爷爷活到95"信息量为零。
