## 已固化验收规则

1. **两轴分查**（KP1）：看 AI 的论证分两步——先查结构有效性，再逐个查前提真实性（尤其最像常识的那个）。结构完美 ≠ 结论可信。
2. **归因排除问**（KP1）：AI 给唯一归因时必问"排除了其他可能吗？列出其他原因、说明排除了谁凭什么"——列不全只能当假设。注意"典型原因"≠"全部原因"，是局部推全局。
3. **排除检验**（KP2）：AI 缩小排查范围时，检查每步排除是否符合"若X则必有Y；无Y；故排除X"——不符合的排除是拍脑袋。
4. **范围滑动警戒**（KP2）：见"我们的X都→所有X都"句式，查结论主语范围是否比前提大一圈（范围+断言双重滑动）。
