格式约定：每个知识点一节，按"讲解要点 → 我的复述与判断 → 考官纠正"沉淀。消化后的产物，不粘贴 AI 原话。

## KP1 演绎基础（2026-09-08）

### 讲解要点

- 演绎的定义性特征：前提真则结论必然真。三段论 = 两个前提共享中项，把两端连起来。
- **有效性 vs 真实性是两个独立的轴**：有效性只看结构（前提真则结论必然真这个条件是否成立），真实性看前提是否符合事实。可组合出"有效但结论假"（鱼会飞例）和"前提假但结论碰巧真"（猫是爬行动物例）——后者证明：有效性是结构质量，不是通向真理的通行证。垃圾进垃圾出，但输出与输入严格连贯。
- 常见无效结构：**未分配中项**（两个前提都只说"猫/狗是哺乳动物"，中项没和"全部"锁死，两端没连起来）；**肯定后件**（把"如果P则Q"当"如果Q则P"用，充分条件被当必要条件——石墨导电但不是金属）。前提全真、结论也真，结构照样可能无效（C例）。
- 对 AI 产出的意义：AI 的回答 = 前提 + 推理链。链条可以完美有效、前提是错的 → 看起来逻辑严密，结论是垃圾。只查"推理顺不顺"会放过最大的坑；结构完美时唯一能错的是前提，验收动作 = 查前提。
- 归因场景的肯定后件：AI 说"偶发500通常是连接池耗尽（前提真）→ 现在偶发500 → 所以是连接池耗尽"。结构无效：500 的原因是一个集合，它只给了其中一个成员。

### 我的复述与判断（第一轮）

- 第1问我分出了有效/真实两个轴，但说"原语假的还谈什么推理"——暴露残留误解：前提假时结构照样要独立检查。纠正后接受"两道检查独立进行"。
- 第2问我答"前提全假则推理无效"——fail，把两轴绑死了。反例（猫是爬行动物→猫是动物）让我看到结论可以碰巧为真。
- 第3问我答"无效"，理由是"能用窗口函数不等于要用"——混淆了结构审查和决策审查两个层次；结构上它是有效三段论，真正的验收动作是查前提（我们的库真是8.0吗？）。
- A/B/C 判定：A 对但措辞混（"真实性有效"不存在）；B 判对且理由对（推不出）；C 我先造了一个同款错误改写、又独立识破"有点反了"——语义直觉强、结构直觉不稳。
- 反方证据轮：肯定后件术语落位正确；实战动作"要证据、先复现、再确认"是实战级——pass。

### 考官纠正 → 固化规则

1. **两轴分查**：看 AI 的论证永远分两步——先查结构（有效吗），再查前提（每个前提真吗，尤其那个最像常识的）。结构完美 ≠ 结论可信。
2. **归因排除问**：AI 给出唯一归因时必问："这个结论排除了其他可能吗？列出同类现象的其他原因，说明你排除了谁、凭什么。"列不全/排不出 → 它的诊断只能当假设，不是结论。

## KP3 归纳与最佳解释推理（2026-09-09）

### 讲解要点

- 演绎：结论不超出前提。归纳：从"见过的都这样"推"都这样"，结论超出现察——休谟问题：归纳的正当性无法被演绎证明（要证明就得假设"未来像过去"，循环）。归纳结论**永远是暂定为真**，一颗黑天鹅就能推翻。
- 溯因（最佳解释推理）：从观察反推最佳原因。形式永远无效（本质是肯定后件），但医生看病、破案、诊断全是它。正确用法：**列全候选池 → 逐个找区分性证据 → 剩下解释力最好的**。AI 的病不是用溯因，是**池子里只放一个成员**就宣布结论。
- 三种推理不是并列关系，是一套流水线的分工：**归纳供弹药（归纳律做大前提）、演绎当枪管（有效结构）、溯因做瞄准（从现象到假设）**。"内存泄漏最终 OOM"的演绎，其大前提本身就是归纳律。
- 关键不对称：归纳/溯因的结论是"目前最佳，可被推翻"；演绎的结论是"跟着前提走"。
- "八成是流感"的解剖：数字是**未声明的归纳前提**（个人经验分布）伪装成概率。检查两问："这个比例的样本是什么？跟我眼前这个 case 匹配吗？"
- CPU 100% 的候选池补全：OOM/死循环/内存泄漏致频繁 GC/日志同步刷盘/正则回溯/定时任务撞点/外部调用变慢占满线程池——**CPU 高有时是受害者不是凶手**。即使确认资源不足，"扩容三台"的"三台"也要追问来源（压测数据还是拍的）。

### 我的复述与判断（第一轮）

- 我说溯因"损失池子里其他数据、保留强行列出"——**表述反转**：损失的是确定性，保留的是可行动性，"列全候选池"是正确操作不是它保留的价值。口误还是混乱经反方证据轮确认：口误。
- 我判定 AI"CPU 100% 所以资源不足要扩容"是溯因，列出 OOM、死循环两个隐藏成员——pass。
- 三句话辨析：归纳/演绎/溯因全对，且我自己造出"医生A是先归纳后溯因"的精确描述。
- 我答"八成是之前归纳出来的"——直指未声明前提。

### 考官纠正 → 固化规则

1. **候选池两问**（溯因审计）：AI 给诊断/归因时问——"候选池里有谁？"（只有一个成员 = 没诊断，只有断言）+"用什么区分性证据切开的？"（没有证据切换 = 拍脑袋选中）。
2. **伪概率审问**：AI 说"通常/大概率/八成"时问——"这个比例的样本是什么？跟眼前这个 case 匹配吗？"
3. **处方来源问**：AI 给具体数字的处方（扩容三台/重试三次）时问——"这个数字怎么得出的？压测数据还是拍的？"

## KP4 认知偏差精选（2026-09-09）

### 讲解要点

- 卡尼曼双系统：系统 1（快/自动/省力/联想直觉）是**进化装配的默认引擎**，95% 日常决策靠它且大多干得不错；系统 2（慢/费力/逻辑核对）。偏差根源 = 系统 1 抢答 + 系统 2 没被叫醒。**不是"想偷懒"，是现代统计/概率/长链推理题型是进化中没见过的，系统 1 却照答不误。**
- 训练重点不是"多思考少直觉"（会累死且没必要），是**识别系统 1 不擅长题型的信号**（数字/概率/样本/因果/大额决策）→ 强制切换系统 2。训练触发器敏感度，不是全局用脑强度。
- 四大偏差（生活识别版）：
  - **确认偏差**：只搜集/记住支持已有结论的证据。阴处是主动行为——跳过批评、点开好评。反义动作 = 专门去找证明自己错了的东西。
  - **锚定效应**：第一个数字/框架被免费安装为参照点。砍价 500→300 觉得赚 200，实际真实价值 250 时是**多付 50**。解药 = 进场前独立估价。
  - **可得性启发**：频率感被曝光量替代。"罕见才上新闻"+天天安全不上新闻——和幸存者偏差联合作案。
  - **幸存者偏差**：样本 = 活下来/被看见的，死掉的不在样本里。返航轰炸机弹孔（该加固没弹孔处）；"我爷爷抽烟活到95"——**活到 95 的人才有机会讲这句话，该话信息量为零**；正确视角 = 把没活下来的放回样本（查全人群发病率对比）。
- 偏差现实里总是**团伙作案**：识别一个后要扫同伙。
- 通用解药：系统 2 上岗靠**流程外部脚手架**（排除问/候选池问/伪概率审问），不靠意志力。

### 我的复述与判断（第一轮）

- 四偏差识别 a/b/d 全对且机制完整（主动选择、曝光量替代频率、参照点安装）。
- (c) 判定对但"正确视角"给成了同一个偏差换个例子——被考官按住：全样本 = 把死掉的放回来，查发病率数据。
- 第 2 题"直觉是想偷懒"被修正：默认引擎 + 题型不匹配，训练的是触发器敏感度。
- 第 3 题自发完成三偏差联合作案分析——全对。

### 考官纠正 → 固化规则

1. **反例搜索**（确认偏差解药）：对已形成的判断，强制执行"专门去找能证明我错了的信息"动作——违反直觉，靠清单强制。
2. **独立估价**（锚定解药）：任何谈判/评估前，先独立得出自己的数字再听对方的。
3. **全样本校正**（幸存者偏差解药）：听到"某人/某案例"先问"没成/没活/没出声的在哪？"——把缺席者放回样本。

## KP2 无效推理形式（2026-09-08）

### 讲解要点

- 条件推理四式：肯定前件（P→Q；P；∴Q）**有效**；否定后件（P→Q；¬Q；∴¬P）**有效**；肯定后件（P→Q；Q；∴P）**无效**；否定前件（P→Q；¬P；∴¬Q）**无效**。两个无效式是同一个错误的两面：**把充分条件错当必要条件**。
- 否定后件是排除法的逻辑武器："如果 X 是真凶，现场必有 Y；无 Y；排除 X"——检验 AI 排查/缩小范围时的排除逻辑。
- **换位不保真**：全称命题只有主语被"所有"覆盖，反向不成立（所有猫是动物 ↛ 所有动物是猫）。AI 变体："我们的 X 都如何 → 所有如何的都……"识别标志：**结论主语范围比前提大一圈**（范围滑动 + 断言偷换双重滑动）。
- 大公司微服务例的完整拆解：结构是有效三段论，但前提"大公司都用微服务"可疑（幸存者偏差：死了的单体不上新闻），且小前提"要成为大公司"把将来时偷换成现在时。

### 我的复述与判断（第二轮）

- 第1问：挖出两个隐含前提（幂等只能靠分布式锁；分布式锁只管幂等）并给出反例路子（唯一索引/幂等令牌/状态机）——pass 超预期。
- 第2问：结论对但没点出"换位不保真"名与范围滑动结构——方向 pass，结构命名 fail。
- 第3问：前提嗅觉准（大公司全用微服务不成立），但结构判定跳过——考官补讲：结构有效 + 时态偷换。
- 反方证据轮 D/E/F：**三题全对且"只判结构"纪律执行到位**——肯定后件、否定后件（最难的一个）、否定前件全部独立判对。

### 考官纠正 → 固化规则

1. **结构优先纪律**：判 AI 论证时先单独完成结构判定（有效/无效+命名），再查前提。结构判定是慢功夫，刻意降速，禁止两步混着走。
2. **排除检验**（否定后件的实战用法）：AI 缩小排查范围时，检查它的每一步排除是否符合"若X则必有Y；无Y；故排除X"——不符合的排除是拍脑袋。
3. **范围滑动警戒**：见"我们的X都→所有X都"句式，查结论主语范围是否比前提大一圈。

## KP5 论证体检（2026-09-09，综合收口）

### 讲解要点

五站流程（30 秒过 0-3 站，第 4 站重要决策全开）：

- **第 0 站 · 还原**：拆出前提/结论/**隐含前提**（"要这个结论成立必须再默认什么"）。隐含前提常埋在：默认选项（"存银行"被当无风险基准——不比较的默认选项也是选项）、样本代表性。
- **第 1 站 · 结构**：只看形式，不管真假。警惕**善意抢答**——把对方的话脑补成合理形式再判它成立；体检对象是他实际说出的结构。
- **第 2 站 · 前提**：真吗（尤其最像常识的）？哪来的（观察/权威/未声明归纳）？全样本校正了吗？缺席者是谁——**缺席者方向取决于传播性质**：谈亏钱时缺席的是赚钱的（悄悄赚不说话），谈抽烟时缺席的是死掉的（没法上桌）。
- **第 3 站 · 类型/语气匹配**：演绎（必然）/归纳（暂定）/溯因（最佳猜）——**结论语气必须匹配类型**。归纳配全称（"永远/所有/玩不过/白学"）= 语气超标。
- **第 4 站 · 偏差自查**：查**自己**——反驳冲动本身可能是确认偏差反向（已认定对方错，只搜他漏洞）；**他论证烂 ≠ 他结论假**（两者可同时成立）。
- **出站定级**：接受（演绎+前提真）/ 暂定接受（归纳溯因+前提站住）/ 打回（结构无效或前提假）/ 挂起（列证据缺口）。不允许"感觉还行"。

### 我的复述与判断（第一轮）

- 第 0 站拆了明面前提结论，漏了两个隐含前提（样本代表性、"存银行"默认基准）。
- 第 1 站判"有效"——善意抢答，替对方修好了论证；实际结构是未分配中项的归纳跳跃。
- 第 2 站最亮："不是投资者亏损，是他认识的人亏损"——样本问题点中。
- 第 3 站判"语气没超标"——漏了全称结论（玩不过/白学）配归纳证据的严重超标。
- 第 4 站扫出了他（确认/可得性）但没自查（反驳冲动=确认偏差反向）。

### 考官纠正 → 固化规则

**五站体检清单**（按序执行、不许跳站——跳站不是省时间是给偏差留后门）：
0. 还原：前提/结论/隐含前提（默认选项也是选项）
1. 结构：只看形式（防善意抢答：别替对方修论证）
2. 前提：真吗/哪来的/全样本（缺席者按传播性质找）
3. 类型语气匹配：归纳配全称=超标
4. 自查：我中哪个？（反驳冲动也是偏差信号）
出站：接受/暂定/打回/挂起，四选一，禁止"感觉还行"。
