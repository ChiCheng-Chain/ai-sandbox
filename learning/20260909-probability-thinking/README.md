## 薄弱点

- 自述数学恐惧——已销案：概念全过，卡点是"百分比+条件方向"的表述形式。后续涉及计算的题目保持"概念优先、频率化兜底"的出题方式，计算交给工具，训练目标是三问直觉（基数/方向/基础比率）。

## 已固化验收规则

1. **百分比三问**（KP1）：见统计声明先问基数多少、箭头哪头指哪头、缺不缺基础比率。
2. **环境校正**（KP1）：数字只在采样环境里有效；被筛过人群里的观察频率不能反推整体。
